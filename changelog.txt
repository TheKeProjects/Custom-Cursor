3.0.0 | 09/11/26
## Redesigns
- New look: a side bar with animated navigation, banners and redrawn menus
- Scheme cards: animated cursor on a glowing stage, active and installed badges
- Categories are now chips with their counts, the highlight sliding between them
- Preview: a big stage for any cursor of the scheme, click a card to see it there
- Selecting schemes brings up a bar to install them all or clear the selection
- Updates and Changelog are pages of their own
- New logo: Clicky
## Seasonal Themes
- Halloween, Summer, Christmas and LGBTQ+ themes: colours, scenery, particles and logo
- Default theme: follows the season of the current release
## Additions
- Languages: English, Spanish, French and Italian
- The search box finds schemes by name or folder
- Animated previews for the schemes with a GIF
- Installing several schemes shows real progress and each scheme's own result
## Performance
- Long operations no longer freeze the window
## Bug Fixes
- Offline, the updates page says it couldn't check instead of "You're up to date"
- The manual update no longer installs an older version over a newer one
- Schemes with accents or other alphabets in their name no longer overwrite each other
- Uninstalling can no longer remove Windows' own cursors
- Approving the admin prompt with another account changes your cursors, not that account's
- Cancelling the admin prompt no longer leaves a temporary file behind
- Animated cursors with an odd-sized frame no longer lose the following frames
